# Changelog

Versions are `<Alloy version>.<release>`. A version ending in `.0` without
an entry here only updates Alloy: see its
[release notes](https://github.com/grafana/alloy/releases).

## 1.21.3.1

- The options `metrics_api_key` and `logs_api_key` are now `metrics_token`
  and `logs_token`: set them again after the update, the app doesn't start
  without them.
